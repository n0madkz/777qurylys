# Поиск фото для товаров

1. В https://api-dashboard.search.brave.com/ зарегистрироваться, выбрать план
   с доступом к Image Search и создать API key. Условия и стоимость проверить
   в кабинете перед подключением; платёж выполняет владелец аккаунта.
2. В Plesk добавить в существующий серверный `.777qurylys.env` строку:
   `BRAVE_SEARCH_API_KEY=ваш-ключ`. Не добавлять ключ в Git или JavaScript.
3. Получить обновления Git и развернуть сайт. Нужны PHP cURL, исходящие HTTPS,
   доступ к Brave API и Supabase Storage. Новый файл: api/photo-search.php.
4. Админка → Товары → Изменить → Найти фото → Искать варианты.
   Запрос формируется из названия, бренда и артикула; его можно редактировать.
5. Проверить модель и источник, выбрать фото и сохранить товар.
   Только после сохранения фото и превью загружаются в Supabase Storage.
   URL страницы источника сохраняется в metadata.imageSource.

Без ключа встроенный поиск показывает сообщение о неподключённом сервисе.
Ссылка «Открыть поиск картинок» работает без ключа: фото можно скачать
с разрешённого источника и загрузить существующей кнопкой в карточке.

Поиск не выдаёт разрешений на использование изображений. Они проверяются
по источнику. Недоступные для скачивания источники, редиректы, приватные
IP-адреса, файлы больше 10 МБ и неподдерживаемые форматы отклоняются.
Оригинал скачивается только по подписанному результату поиска, в течение
15 минут. Фото не публикуется автоматически, статус товара не меняется.

Справочник API: https://api-dashboard.search.brave.com/api-reference/images/image_search

Проверка перед рабочим использованием: без ключа — понятное сообщение;
с ключом — реальные результаты и источники; выбор фото → предпросмотр;
отмена формы ничего не сохраняет; сохранение → собственный файл в Storage;
повторный импорт 1С сохраняет фото. Live-проверка требует рабочего API key.
