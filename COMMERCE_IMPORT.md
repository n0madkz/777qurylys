# Импорт каталога 1С

Реализован ручной импорт пары CommerceML 2.08: `import.xml` и `offers.xml`.
Подготовлен также приёмник автоматического обмена: см. ONEC_AUTO_EXCHANGE.md.
Расписание и доступ настраиваются в 1С и Plesk после контрольного запуска.

На PHP-хостинг загрузить `api/index.php`, `api/commerce-import.php`,
`admin.html`, `admin.js`, `commerce-import.js`. Нужен PHP 8 с SimpleXML.
Миграция базы не требуется: остатки и идентификаторы хранятся в metadata.
XML передаются частями по 128 КБ (JSON-запрос меньше 200 КБ), затем
импортируются порциями по 25 товаров. Увеличение лимита запроса до размера
обоих XML больше не требуется. Каждый XML — до 20 МБ.
Пока файл собирается, исходный XML временно находится в закрытой temp-папке
вне сайта; после разбора удаляется, остаются только поля без цен.
Незавершённые файлы старше двух часов очищаются при следующем импорте.

В админке нажать «Импорт из 1С», выбрать оба файла вместе.
Новые товары создаются скрытыми с ID `onec-<GUID>`.
Существующие товары с этим ID обновляются без изменения активности и фото.
Повторный импорт сохраняет также название, описание, характеристики, бренд,
артикул и вручную назначенную категорию. Обновляются только остатки и
служебные данные 1С (код, штрихкод, единица измерения).
Ранее созданные вручную товары автоматически по названию не сопоставляются.
Категории создаются с отдельными ID, существующие категории не удаляются.
Отсутствующие в выгрузке товары не удаляются и не обнуляются.
Импорт не транзакционный: при ошибке повторить те же файлы.
Ценовые узлы XML не записываются; исходные XML не сохраняются обработчиком.
Остатки видны в списке товаров админки по складам. Интерпретацию остатков
как фактических нужно сверить с отчётом 1С на нескольких товарах.

Проверка на предоставленных файлах:
`php scripts/test-commerce-local.php /path/import.xml /path/offers.xml`

После размещения проверить тестовый импорт и повторный импорт: число товаров
не растёт, активация сохраняется, склады совпадают с 1С, цен в новых записях нет.
Затем отдельно настроить безопасную автоматическую отправку ежедневно
в 01:00 по Астане (UTC+5). Этот HTTP endpoint требует сеанс администратора
и не предназначен для отправки из 1С по расписанию.
