# Новости и каталог

После развёртывания Git: в админке раздел «Новости и советы».
Создать запись, выбрать тип (новость/полезный совет), заголовок, анонс,
блоки текста и изображений, обложку (файл или HTTPS-ссылка) и флаг публикации. Для снятия с
публикации снять флаг и сохранить. Черновики не отдаются публичным API.
Текст обычный, без HTML; абзацы разделяются пустой строкой.
Кнопки «+ Текст» и «+ Изображение» добавляют блоки в любом порядке;
стрелки меняют порядок, «Удалить» убирает блок. У изображения есть
описание для доступности и подпись. Всего до 60 блоков. Изображения
загружаются отдельно и сжимаются до WebP; исходный файл до 10 МБ.
Старые записи с одним текстовым полем открываются как один текстовый блок.

На главной появляются три последние публикации. Все записи доступны на
news.html, полная статья — news.html?id=ID. Категории меню берутся из
существующих категорий сайта, группы 1С не добавляются и не показываются.

Данные новостей по умолчанию хранятся в `.777-news.json` на уровень выше
httpdocs (для этого каталога у PHP должны быть права записи).
Импорт товаров и развёртывание Git этот файл не меняют. SQL-миграция не нужна.
Добавьте файл в резервное копирование Plesk вместе с файлами сайта.
При ошибке доступа укажите в `.777qurylys.env` абсолютный путь вне httpdocs:
`NEWS_DATA_PATH=/var/www/vhosts/777qurylys.kz/.777-news.json`.
Файл создаётся при первом сохранении, права 0600. Его не добавлять в Git.
Обложки загружаются в существующий bucket product-images в папку news/.

Контроль на хостинге: создать черновик — на сайте его нет; опубликовать —
виден на news.html и главной; исправить текст; снять с публикации.
Проверить кнопку «Каталог» на телефоне и компьютере, вложенные разделы,
ссылку «Все товары раздела», закрытие меню по Escape/нажатию вне меню.
